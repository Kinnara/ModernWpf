## Release-blocker assessment

No applicable Preview 2 source change was found. In particular, the upstream
keyboard fail-fast, WebView2 threading failure, InkCanvas lifetime work,
MediaPlayerElement callback leak, MapControl token error, and XAML Island UIA
crash are real fixes but do not execute in a control or framework primitive
implemented by ModernWpf. The Gallery accessibility/focus/contrast fixes are
confined to pages that the checked-in WPF Gallery catalog explicitly excludes.

No existing mapped control-family runtime, API metadata, theme dictionary,
resource, test, or Gallery source path changed. The cutoff therefore requires
no ModernWpf product code, public CLR inventory, public resource-key inventory,
template, visual baseline, or migration edit.

## Milestone policy and monitoring

`tools/upstream/upstream-sync.json` records the milestone, cutoff date, exact
revisions, and this disposition for all three tracks. Advancing the product and
Gallery epoch targets makes this immutable review the Preview 2 source
boundary. The moving selectors remain unchanged, so later commits are still
reported on the weekly/manual monitor.

Post-cutoff movement starts the next finite review interval and does not by
itself invalidate Preview 2. An applicable security, data-loss, startup,
crash, or equivalent critical change in a shipped surface remains an exception
and must be assessed before release, as required by
`docs/release-readiness-1x.md`.
